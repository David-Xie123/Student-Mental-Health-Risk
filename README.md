# Student-Mental-Health-Risk
## Project overview
This project analyzes whether physiological and behavioral measurements conducted by Fitbit wearables are associated with college students' self-reported stress and anxiety. The primary question is whether these relationships are consistent across across participants or vary from person to person.

The analysis uses a publicly available SSAQS dataset, which combines Fitbit Inspire 3 measurements with daily reported stress and anxiety rates through the m-Path mobile application.

Main finding: Participant-level associations are varied in both strength and direction. The pooled cohort-level correlations were close to zero, while HRV showed substantial between-participant heterogeneity.
